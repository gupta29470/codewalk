# `src/codewalk/ingestion/` — File Discovery & Filtering

This package decides which files enter the Codewalk pipeline and tags them with language/tech metadata.

## Modules

| File | Role |
|------|------|
| `scanner.py` | `scan_directory()` — `os.walk`-based discovery. Uses `file_filter` core safety net to skip hidden dirs, binaries, build artifacts, `.git`, etc. |
| `file_filter.py` | `should_skip_dir()`, `should_skip()`, `.codewalkignore` parsing. Core safety net only (dependencies, build/cache output, binaries, secrets, generated artifacts). |
| `tech_detect.py` | `detect_tech_stack()` — heuristically identifies languages/frameworks from file presence. |
| `config_generator.py` | `generate_codewalk_yaml()` — creates a starter `codewalk.yaml` with stack-specific exclusions. |

## How it connects

- `scanner.scan_directory()` is the **default** filtered scan used by `pipeline.py`, `api/state.py`, and `index_from_paths_parallel()`.
- `team_config.team_scan_directory()` (in `src/codewalk/team_config.py`) merges three layers:
  1. `codewalk.yaml` `indexing.include` — overrides exclusions for specific paths.
  2. `file_filter.py` core safety net — always excludes dependencies, build artifacts, binaries, secrets, etc.
  3. `codewalk.yaml` `indexing.exclude` — repo- and stack-specific patterns.
- `repo_discovery.ensure_codewalk_yaml()` auto-generates a stack-specific `codewalk.yaml` when one is missing, so users do not need to duplicate the core safety net.
- Detected tech stack is logged by `pipeline.py` and the CLI but is not stored in the index.

## Exclusion sources

Exclusions are merged from these sources in this priority:
1. `codewalk.yaml` `indexing.include` — whitelists paths that would otherwise be skipped.
2. `file_filter.py` core safety net — `CORE_SKIP_DIRS`, `CORE_SKIP_EXTENSIONS`, `CORE_SKIP_FILES`, `CORE_SKIP_SUFFIXES`.
3. `codewalk.yaml` `indexing.exclude` — repo-specific patterns generated by `config_generator.py`.
4. `.codewalkignore` — gitignore-style patterns in the repo root.

## Output shape

```python
[
  {
    "file_path": "src/main.py",      # relative to repo root
    "absolute_path": "/.../src/main.py",
    "language": "python",
    "size_bytes": 1234,
  },
  ...
]
```

## Downstream consumers

- `embeddings/chunker.py` — turns file dicts into chunks.
- `analysis/dependency_graph.py` — resolves imports between files.
- `analysis/module_detector.py` — groups files into modules.
- `graph/graph_store.py` — populates the `files` table.
